# Playbook: Checagem de Regressao

## Objetivo

Evitar que mudancas quebrem fluxos existentes.

## Passos

1. Listar areas impactadas.
2. Consultar docs relevantes em `docs/`.
3. Verificar decisoes anteriores em `memory/`.
4. Rodar comandos de verificacao disponiveis.
5. Testar manualmente os fluxos mais proximos.
6. Registrar riscos remanescentes.

## Fluxos prioritarios

* Sacola para pagamento.
* Pix/cartao Mercado Pago.
* Loja visualizando pedidos pagos.
* Entregador validando PIN.
* Clube Cosechas e pontos.
